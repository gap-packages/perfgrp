This file describes changes in the GAP package PerfGrp.

## 1.0.0 (2026-08-04)

- Initial release. The code and data in this package were previously part of
  the GAP core system, in the files `grp/perf*` and in `lib/grplatt.gi`.
- The package can also be loaded into GAP 4.16 and earlier, which still
  contain the perfect groups library themselves. It then reads none of its
  own files and is simply a no-op.
